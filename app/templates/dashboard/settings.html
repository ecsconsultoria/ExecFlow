Taxas de Cobrança

Usadas para calcular automaticamente preços NF e Cartão a partir do preço base quando não cadastrados manualmente.

Recibo = preço base (sem acréscimo)

Nota Fiscal = base × (1 + taxa NF) quando preço NF não cadastrado

Cartão = base × (1 + taxa cartão) quando preço cartão não cadastrado

NF + Cartão = base × (1 + taxa NF + taxa cartão)
